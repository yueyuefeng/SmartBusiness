# 09 合同、硬件与 ESG 专项

## 1. 合同闭环

范围：模板与条款库 → 商务草稿 → 差异审查 → 内部授权 → 对外发送/签署 → 生效 → 义务分配 → 验收 → 结算 → 变更/终止/归档。

合同草稿包含交易主体、授权签署人、范围与附件、价格和税费、币种、交付与验收、付款、质保售后、知识产权、保密、违约与争议条款。此为数据设计清单，不是法律模板或适用法律结论。

AI 可做条款抽取、缺失提示和版本差异说明；风险结论由指定人员复核。禁止把“AI 未发现风险”显示为“法律有效”。

合同主体、已签文件哈希和附件版本冻结；CRM 名称更新不覆盖历史。签署服务返回成功只是一份待验证证据，ContractExecuted 还需符合合同生效条件。每项 Obligation 指定负责人、触发条件、日期、所需证据与状态。电子签服务商、地区可用性和效力验证另作接入评估。

示例：订单要求交付固件 v2 + BOM R3，合同附件仅签署了 R2 → 系统提示基线不一致并发起变更，而不是自动把附件替换成 R3。

## 2. 软件与硬件协同

同一 RequirementBaseline 可映射软件需求、硬件需求及系统级验收。工程基线固定软件/固件制品哈希、硬件修订、接口协议版本和适用设备批次。

硬件主流程：需求 → 架构/接口 → 元件与供应商 → EBOM/图纸 → 工程评审 → 样机 → 验证/确认 → 工程变更 → 小批验证 → 受控交付 → 现场质量反馈。阶段名称和进入条件按产品类型配置，不把所有硬件都套同一研发模板。

|能力|模型要点|验证例|
|---|---|---|
|物料与 BOM|料号和修订、数量单位、替代关系、生命周期、供应证据|自引用或跨层循环拒绝；替代料必须对应批准记录|
|设计文件|原理图、PCB、机械图等作为受控文件，关联来源工具与修订|上传新文件不得悄悄替换已发布基线|
|ECR/ECO|原因、成本/交期/固件/认证影响、审批和生效批次|库存旧料与在途货的处置必须明确|
|样机与测试|样机序列、BOM/固件、工装、环境、仪器校准引用、结果和原始数据|测试结果不可借用其他修订样机作为“本版已通过”|
|供应质量|准入、样品、检验、不符合项、纠正行动和追踪|质量问题可回溯批次、订单与客户|
|软件协同|接口契约、固件兼容矩阵、HIL、回归|不兼容固件与硬件组合禁止标记可交付|

首期管理与集成已有 CAD/EDA/PLM 的产物，不开发绘图编辑器。工程仿真不等于实物验证；硬件样机测试也不应被软件单测通过替代。用户如果只是转售商品，走交易/采购/物流，不强制建立研发项目。

## 3. ESG 口径与报告链

报告输入必须先确定报告实体、期间、组织边界、重大性方法、适用准则版本及排除说明。GRI 强调影响相关重大议题；IFRS S1/S2 面向可持续相关财务与气候披露；GHG Protocol 提供排放核算框架。三者不能简化成同一模板或互相替代。参见[官方资料](13-研究来源与核实状态.md) S07–S09。本文不判断用户公司是否受到某项披露义务约束。

|类型|指标候选|必要证据与约束|
|---|---|---|
|E 环境|能源、温室气体、用水、废弃物、材料|账单/计量、因子版本、单位、地区、时间与组织边界|
|S 社会|员工培训、健康安全、劳动实践、供应商评估|去标识统计、分母口径、资料访问范围和报告期间|
|G 治理|决策授权、商业道德培训、举报处理、供应商治理|治理政策版本、执行记录和访问控制|

每个指标有 metricDefinitionId、standardVersion、boundaryVersion、period、value、unit、qualityStatus、evidenceRefs、methodVersion、reviewer。qualityStatus 至少区分实测、估计、缺失、不适用；零必须有依据。

碳排简化教学例：活动量 1,000 kWh × 示例因子 0.5 kgCO2e/kWh = 500 kgCO2e = 0.5 tCO2e。**0.5 为纯演示参数，不是实际地区排放因子**。生产需采用经确认的因子来源、适用年度、地区和方法；不得重复加入已折算的全球增温潜势。范围二的位置法/市场法及范围三类别适用规则由专业人员配置和复核。

## 4. 发布与重述

ObservationSubmitted → DataVerified → CalculationRunCompleted → ReportReviewed → ReportApproved → ReportPublished。

发布快照保存指标值、输入引用、单位转换、因子、边界、计算程序与模板版本、审批记录。缺数据时展示缺口和处理说明，不填零掩盖。报告正式发布是否允许特定缺口，由适用框架及经批准政策决定，不用一个通用规则擅自宣称合规。

修改原始数据或因子后，只创建新 CalculationRun 和 ReportRevision；旧报告保持可复现，标明重述原因和差异。报告可以输出 HTML/PDF/表格，具体导出工程在开发阶段完成，本轮未生成 ESG 报告。

## 5. 共同的证据治理

三类领域共用文件存储，但保留期限、合法处理依据、有效性审核和访问规则由各领域负责。合同证据不能因为营销同意撤回就不加判断地销毁；营销撤回也不能因为合同保留而继续联络。系统表达不同用途的状态，具体裁决交给有授权的负责人。

保全例外必须有理由、范围、期限/复核日期和批准人。到期删除传播到搜索索引、缓存和派生材料；备份采用到期销毁并在恢复后重放删除清单。审计保留最小操作事实，避免永久复制敏感正文。
