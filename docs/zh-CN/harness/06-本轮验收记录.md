## 结构与限制

工作台可真实保存本地业务记录；六个案例及其收益始终是独立合成模型，不能把已录入访谈等同于真实利润。模型状态显示“未探测”，工作台不假装知道官方 Harness 内部模型配置。

浏览器内部审核是试点的操作入口，Harness Bearer 凭据只能执行 Agent 操作。精确白名单约束经过官方 ToolRuntime 的工具调用；恶意同进程插件、主机管理员及其他本机进程不在这个隔离边界内。生产需独立用户身份、隔离运行时、最小权限和外部动作审批。

响应式 CSS 已编写，但本轮视口覆盖工具没有改变实际页面宽度，因此不把手机视口列为已通过。Android、iOS、macOS、Ubuntu 与 Windows 安装包都需后续实机验收。

## 复现命令

```text
python -X utf8 -m unittest discover -s tests -v
python -X utf8 scripts/check_harness_integration.py
python -X utf8 scripts/check_design_docs.py
cd integrations/deepseek-harness
npm test
```

不提交 `.smartbusiness/`、真实令牌、模型密钥、个人会话、node_modules 或本地数据库。启动产生的临时配置留在本机，代码和验证日志单独提交。
