# 07 运行方式、结果与 TDD 记录

## 1. 运行

在仓库根目录，使用 Python 3.14（本次实测环境；只依赖标准库）：

```text
python -X utf8 -m unittest discover -s tests -v
python -X utf8 -m industry_pilots.runner --output examples/results/industry-report.json
python -X utf8 scripts/check_design_docs.py
```

默认读取 examples/industry 下六个 JSON；可用 --cases 指定另一合成数据目录。运行器没有网络、数据库、社交外发或设备控制；拒绝 synthetic=false。格式无效抛出错误，业务约束不满足输出原因。

## 4. 计算口径

能源费用：区间购电量×买价 − 售电量×卖价；基线为同一负荷/热泵时序不使用电池。电池初末能量或储热初末不相等时不输出可比费用节省；不合格调度不输出收益。需量费仅在输入声明覆盖完整计费期且方案可比时计算；真实日历数据覆盖与费率复杂规则仍由生产上游校验，样例不能替代该校验。

备电检查只用初始可用电能与负荷/峰值，不假定停电期间未知光伏或电网仍可供能，且依赖已审核的孤岛拓扑。

出行：电池Wh×可用比例 / 工况Wh每公里，形成区间；未模拟温度/风/路况的完整车辆动力学。

利润：净收入=收入−退款；毛利=净收入−直接成本；贡献=毛利−可变成本。缺失必需成本返回 incomplete 和空利润；估计返回 estimate；同币种才计算。confirmed_inputs只指输入标记，并非软件核实了真实账目。
