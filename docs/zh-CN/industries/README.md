# 两行业落地试点 v0.3

用户指定：家庭多能源/商业储能，以及电动摩托、电动自行车、自行车电助力改装。目标为欧美和国内一二线城市，具体国家、州、城市、工厂、供应商与渠道尚未确定。

交付为**行业工作包 + 可运行的领域验证内核**。可验证六个合成案例的技术约束、资源证据、利润与流程；尚未真实获客、认证、施工、改装或成交。

|案例|收费方式候选|当前验证重点|
|---|---|---|
|EN-H01 家庭光储备电|需求诊断、安装商线索服务、系统经销集成|功率、电量、备电边界与安装售后成本|
|EN-H02 家庭电热协同|方案、集成、HEMS 服务|光伏、电池、热泵、储热分账|
|EN-C01 商业储能|电费诊断、设备/EPC、运维|计费期、需量、电价与可核证效果|
|MO-E01 电动自行车|整车经销、试骑与售后|市场分类、工况续航和服务成本|
|MO-M01 电动摩托|经销与车队服务|独立车型/登记路线、备件与交付|
|MO-K01 自行车电助力改装|适配评估、套件、专业安装|原车、结构/制动和电池充电组合证据|

仓库根目录运行：

```text
python -X utf8 -m unittest discover -s tests -v
python -X utf8 -m industry_pilots.runner --output examples/results/industry-report.json
python -X utf8 scripts/check_design_docs.py
```

[案例输入示例](../../../examples/industry/EN-H01.json) 和[运行报告](../../../examples/results/industry-report.json) 全部是虚构参数/资源。运行器拒绝 synthetic=false，不执行真实业务。

40 项测试通过；六个默认案例因地区规则和内容证据未确认而停止后续推进，改装另缺车架评估。全链路合成测试验证模拟门槛满足时能推进到复盘。测试环境为 Python 3.14，只依赖标准库，其他版本未实测。

该内核是可执行业务规格，不替换 Java + Flutter 生产架构候选，尚未提供正式后端服务或五端客户端。
