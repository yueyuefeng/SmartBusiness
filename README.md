# SmartBusiness 智能商业协作系统

本仓库用于建设覆盖内贸与外贸的市场情报、资源发现、商业模式、营销、交易、交付、利润复盘和 ESG 的业务系统。

当前阶段：**需求与设计基线 v0.2，2026-09-18**。本次交付为中文设计文档，不代表已经实现或完成上线验证。用户已明确：面向外贸和内贸，以快速发现需求、寻找并整合资源、形成商业模式和获取利润为目标；支持信息中介、软件交付、硬件产品销售，包含内容制作与发布助手。具体细分行业、规模、地区、首批渠道和报告准则尚待确认。
